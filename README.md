# DotfilesCloud

Rules and helpers for cloud Claude Code sessions. Public on purpose: nothing personal, no secrets.

- `CLAUDE.md`: global rules (commit to main, no PRs, versioning, repo selection)
- `guides/`: evidence, security, frontend and subagent guides, read on demand
- `commands/ship.md`, `scripts/`: the `/ship` command with automatic patch bumps
- `install.sh`: copies everything into `~/.claude`

Run `./install.sh` from a setup script after cloning.
